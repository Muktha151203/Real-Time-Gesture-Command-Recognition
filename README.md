# Real-Time-Gesture-Command-Recognition


A machine learning and computer vision based system that detects and recognizes predefined hand gestures in real time using a webcam feed. The project is capable of identifying gesture commands such as **Up, Down, Call Me, Super, I Am Fine**, and more, enabling intuitive human-computer interaction.

## Features

* Real-time hand gesture detection
* Pretrained gesture command recognition
* Live webcam-based prediction system
* Computer vision powered gesture tracking
* Interactive and lightweight implementation
* Scalable for adding custom gestures

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy
* Scikit-learn / TensorFlow *(whichever you used)*

## Working

The system captures live video input from the webcam, extracts hand landmarks using computer vision techniques, and classifies the detected gesture using a trained machine learning model. The predicted gesture command is then displayed in real time.

## Applications

* Human-Computer Interaction (HCI)
* Touchless control systems
* Smart automation interfaces
* Assistive technologies
* Gesture-based command systems
